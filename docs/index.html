安装命令


              
命令已以空格开头，Debian/Ubuntu 默认不记入历史；其他系统运行后可执行 history -c。

              
需要 root；Alpine 先执行 apk add bash curl。可重复运行：已安装时保留原设置，命令里的参数优先。

            

          

        


        

          
安装后的常用命令

          

            
管理菜单
sb

            
查看节点 / 订阅
sb nodes

            
运行状态
sb status

            
更新脚本并自动刷新配置
sb upgrade

            
安装后开关 WARP（可为 ai / all / 0）
sb set WARP=ai

            
改优选地址
sb set CFIP=地址 CFPORT=443

            
改 Argo 本地端口
sb set ARGO_PORT=8001

            
卸载
sb uninstall
